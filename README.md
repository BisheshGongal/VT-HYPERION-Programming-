# VT-HYPERION Programming

This repository contains the software and programming files for the VT-HYPERION CubeSat project.

## Repository Structure

- `src/` - Source code for the CubeSat
- `docs/` - Programming documentation
- `cad/` - CAD-related files and references
- `.gitignore` - Files Git should ignore

## Branch Structure

- `main` - Stable and reviewed code
- `develop` - Integration branch for ongoing development
- `feature/...` - Branches used for individual features or tasks

Example feature branches:

- `feature/telemetry`
- `feature/sensors`
- `feature/radio`
- `feature/power-management`

## Note
Programmer won't directly push their work to the main branch.
They will first create a feature branch for their work and then open a Pull Request to merge their changes into the develop branch. 
Once the changes are stable and approved, they will be merged into the main branch.
